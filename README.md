# Curve Fit Bench — website

Static multi-page site for Curve Fit Bench
by Shivani Malvi and Satyajit Puhan. Published with GitHub Pages at
https://curvefitbench.github.io/.

Pages: Home, Features, Models, Benchmark, Docs, Plans & licensing, About. The bench itself is in `app/`.
Edit `build.py` and run `python build.py` to regenerate the pages.
